HyperFleet Desire Store API has been deployed.

Check deployment status:
  kubectl get pods --namespace {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

Reach the API:
  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "hyperfleet-desire-store.fullname" . }} {{ .Values.ports.api }}

Health is served on port {{ .Values.observability.healthPort }} and metrics on port {{ .Values.observability.metricsPort }}.

Documentation:
  https://github.com/openshift-hyperfleet/hyperfleet-desire-store/blob/main/docs/config.md
  https://github.com/openshift-hyperfleet/hyperfleet-desire-store/blob/main/docs/metrics.md
  https://github.com/openshift-hyperfleet/hyperfleet-desire-store/blob/main/docs/alerts.md

Database credentials are not part of this chart yet. Pass them with
extraEnv or extraEnvFrom.
